01 · Descripción del problema

Segmentación de clientes en centros comerciales

En el contexto actual del comercio minorista, los centros comerciales generan diariamente una gran cantidad de datos sobre sus clientes: quiénes son, cuánto ganan, cuánto gastan y con qué frecuencia visitan el establecimiento. Sin embargo, disponer de estos datos no es suficiente si no se cuenta con herramientas que permitan extraer conocimiento útil de ellos.

El problema central que aborda este proyecto es la falta de segmentación estructurada de los clientes: sin grupos bien definidos, las estrategias de marketing son genéricas, poco eficientes y no aprovechan el potencial de personalización que ofrecen los datos disponibles. La segmentación permite responder preguntas concretas como: ¿quiénes son los clientes más valiosos?, ¿qué grupos tienen mayor potencial de crecimiento?, ¿a quiénes conviene ofrecer descuentos y a quiénes productos premium?

Objetivo del proyecto

Aplicar K-Means para identificar automáticamente grupos de clientes con perfiles similares, sin necesidad de etiquetas previas, obteniendo una segmentación accionable para decisiones comerciales.

Aprendizaje no supervisado

No existe variable objetivo predefinida. El modelo descubre la estructura oculta en los datos a partir de similitudes entre observaciones, sin intervención humana en la definición de los grupos.

Aplicación práctica (STP)

Los resultados se alinean con el modelo de marketing STP (Segmentación, Targeting, Posicionamiento): segmentar la base, priorizar los grupos objetivo y diseñar propuestas de valor diferenciadas.

Pregunta de investigación

Este proyecto busca responder: ¿Es posible identificar grupos de clientes con comportamientos de compra diferenciados a partir de variables demográficas y de gasto, usando K-Means?

Beneficios esperados para el negocio

  • Diseño de campañas publicitarias personalizadas por segmento
  • Optimización de la disposición de tiendas según perfil predominante
  • Identificación de clientes de alto valor para programas de fidelización
  • Detección de segmentos con potencial de conversión no explotado
  • Asignación más eficiente del presupuesto de marketing

Alcances y limitaciones

  • El modelo es descriptivo, no predictivo: describe patrones existentes
  • K-Means asume clústeres de forma convexa y tamaño similar
  • Los segmentos deben interpretarse con criterio de negocio
  • El dataset es estático; en producción requeriría actualización periódica
  • No se considera la variable temporal (frecuencia de visitas)
02 · Explicación del dataset

Mall Customers Dataset

El Mall Customers Dataset es un conjunto de datos público ampliamente utilizado en ejercicios de aprendizaje no supervisado. Contiene información de {{ total }} clientes registrados en un centro comercial, recopilada a partir de tarjetas de membresía. Aunque es un dataset sintético diseñado con fines didácticos, representa de forma realista las variables que un mall podría recolectar en su operación diaria.

Para este proyecto, el dataset fue obtenido desde un repositorio público en GitHub y cargado directamente en tiempo de ejecución. Su reducido tamaño (200 registros, 5 columnas) lo hace ideal para explorar técnicas de clustering sin necesidad de infraestructura costosa, permitiendo centrarnos en la comprensión del algoritmo y la interpretación de los resultados.

Contexto del Spending Score

El Spending Score es una métrica compuesta creada internamente por el mall. No se trata de un dato directamente observable como la edad o el ingreso, sino de un indicador calculado a partir del historial de compras del cliente: frecuencia de visitas, ticket promedio y tipos de tiendas frecuentadas. Un score alto indica un cliente muy activo y con alto gasto. Esta variable es clave porque representa el comportamiento real, no solo el potencial económico.

Consideraciones sobre el dataset

Si bien el dataset es ampliamente utilizado en la literatura de machine learning, es importante reconocer sus limitaciones: los datos son sintéticos, no incluye variables temporales (como fecha de las compras), y no captura información sobre los productos adquiridos. Con 200 registros, los resultados no son estadísticamente generalizables, pero para el propósito didáctico de este proyecto el dataset es completamente adecuado.

04 · Conceptos principales de K-Means

¿Cómo funciona el algoritmo?

K-Means particiona el dataset en k grupos minimizando la varianza intra-cluster (inercia).

Función objetivo (WCSS)

J = Σⱼ Σᵢ ‖xᵢ − μⱼ‖²

Donde xᵢ son los puntos del clúster j y μⱼ su centroide. K-Means minimiza esta suma iterativamente.

Implementación en Python

import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 1. Cargar y limpiar dataset
df = pd.read_csv(URL_DATASET)
df = df.drop_duplicates().dropna()

# 2. Seleccionar features
features = ["Age", "Annual Income (k$)",
            "Spending Score (1-100)"]
X = df[features].values

# 3. Normalizar (obligatorio para K-Means)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 4. Entrenar modelo (k=5 por método del codo)
modelo = KMeans(n_clusters=5,
                random_state=42, n_init=10)
df["Cluster"] = modelo.fit_predict(X_scaled)

# 5. Centroides en escala original
centroides = scaler.inverse_transform(
    modelo.cluster_centers_
)

08 · Método del codo

Selección del número óptimo de clústeres

El método del codo evalúa la inercia para distintos valores de k. Se elige el punto donde agregar más clústeres deja de reducir la inercia significativamente.

Inercia (WCSS) vs. número de clústeres k

¿Por qué k = {{ nClusters }}?

Analizando la curva, se observa que la reducción de inercia es pronunciada de k=1 a k=5. A partir de k=5 la curva se aplana: añadir más clústeres reduce la inercia de forma marginal sin aportar segmentos interpretables adicionales. Esto indica que k=5 es el punto de inflexión óptimo.

Justificación adicional

Con k=5 se obtienen segmentos con significado de negocio claro: clientes premium, conservadores, impulsivos, estándar y ahorradores. Aumentar k fragmentaría grupos naturales sin mejorar la interpretabilidad.
